M6-S05

Filters & saved views

Every dashboard screen shares the same filter bar — date range, strategy, session, symbol — and any combination can be saved for one-tap reuse (Figure 6.3).

State
View

Filters

Applies to every widget on the current view.

✅Saved as “30-day core review”Applied automatically the next time you pick it from the filter menu.
Elements
  • Shared filter bar — the same component appears (collapsed) at the top of S01–S04, so a trader never has to re-set a filter per screen.
Rules
  • Changing a filter re-queries each active widget at the new scope; it never triggers a recalculation anywhere else in the app (Figure 6.3) — filtering is always a query-time operation.
  • Saved filters are personal to the trader; there is no shared or team-wide filter concept in v1.

M6-S06

Export & share

Turn the current view into a downloadable file, or a read-only link a trader can send to a mentor, coach, or prop firm without giving them app access (Figure 6.2).

State
View

Export & share

Based on your current view and filters.

journal.app/share/8f2a91c…
Elements
  • Export renders a static snapshot of the current view; share link creates a live, scoped, expiring ShareLink instead — the recipient sees the dashboard update, but only within whatever filters were active when the link was created.
Rules
  • A share link is always read-only and always scoped to the filters active at creation — it can never expose more than the view it was generated from, and can never write anything back.
  • Revoking a link takes effect immediately; a revoked link's token is never reused for a new link.
